## Requisitos previos

- Tener acceso a un sistema Linux.
- Disponer de una terminal.
- Conocer conceptos básicos de archivos y carpetas.


## 1. Comandos de navegación

El comando `pwd` muestra la ruta actual en la que se encuentra el usuario dentro del sistema Linux.

Ejemplo:


```bash
pwd
```

 ### Comando ls


El comando `ls` muestra los archivos y carpetas del directorio actual.


````bash
is
````

### cd

El comando cd permite cambiar de carpeta.

````bash
cd
````


## 2. Gestión de archivos

Permite crear una carpeta nueva.


### mkdir

El comando `mkdir` permite crear una carpeta nueva.

````bash
mkdir
````

### rm

El comando rm permite eliminar archivos.

````bash
rm
````

## 3. Tabla de comandos

| Comando | Función | Ejemplo |
|----------|----------|----------|
| pwd | Muestra la ruta actual | pwd |
| ls | Muestra archivos y carpetas | ls |
| cd | Cambia de directorio | cd Documentos |
| mkdir | Crea una carpeta nueva | mkdir prueba |
| rm | Elimina un archivo | rm archivo.txt |
